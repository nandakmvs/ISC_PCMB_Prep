**Q9: LPP Formulation.**

Subject to constraints:

**$x \ge 0, y \ge 0$** *(These are the non-negativity constraints. Forgetting to write these loses an entire mark in the board exam).*

**Q10: Discuss the continuity of the given function.**
**Perfect ISC Answer:**
*Never abandon a calculation halfway!*
Find the Left Hand Limit ($\lim_{x \to a^-} f(x)$).
Find the Right Hand Limit ($\lim_{x \to a^+} f(x)$).
Find $f(a)$.
If LHL = RHL = f(a), it is continuous. If not, state clearly that it is discontinuous.

**Q11: Differentiate using Logarithmic Differentiation.**
**Perfect ISC Answer:**
$u = x^{\sin x}$
Take log on both sides: $\ln u = \sin x \cdot \ln x$.
**Differentiate implicitly with respect to x:**
$\mathbf{\frac{1}{u} \cdot \frac{du}{dx}} = \sin x \cdot \frac{1}{x} + \cos x \cdot \ln x$
$\frac{du}{dx} = u \left( \frac{\sin x}{x} + \cos x \ln x \right)$
*(Forgetting the $\frac{1}{u}$ on the left side is a fatal algebra error).*

**Q12: Find the intervals where the function is increasing or decreasing.**
**Perfect ISC Answer:**
*Never leave a calculus question entirely blank. Finding the first derivative secures step marks.*
1. Find $f'(x)$.
2. Set $f'(x) = 0$ to find critical points.
3. Draw a number line with the critical points.
4. Test a value in each interval to see if $f'(x)$ is positive (increasing) or negative (decreasing).
