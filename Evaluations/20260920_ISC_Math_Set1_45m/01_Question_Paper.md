## SECTION A (5 Marks)
*Answer all questions. Each question carries 1 mark.*

**Question 1:** Let $R$ be a relation on the set $N$ of natural numbers defined by $n R m$ if $n$ divides $m$. Then $R$ is:
(a) Reflexive and symmetric
(b) Transitive and symmetric
(c) Equivalence
(d) Reflexive, transitive but not symmetric

**Question 2:** Find the principal value of $\sin^{-1}\left(-\frac{1}{2}\right)$.

**Question 3:** If $A$ is a square matrix such that $A^2 = I$, then $(A - I)^3 + (A + I)^3 - 7A$ is equal to:
(a) $A$
(b) $I - A$
(c) $I + A$
(d) $3A$

**Question 4:** Find the unit vector in the direction of vector $\vec{a} = 2\hat{i} + 3\hat{j} + \hat{k}$.

**Question 5:** If $P(A) = \frac{1}{2}$, $P(B) = 0$, then $P(A|B)$ is:
(a) $0$
(b) $\frac{1}{2}$
(c) Not defined
(d) $1$

## SECTION B (8 Marks)
*Answer all questions. Each question carries 2 marks.*

**Question 6:** Differentiate $y = \log(\sin(e^x))$ with respect to $x$.

**Question 7:** Check if the function $f: \mathbb{R} \to \mathbb{R}$ defined by $f(x) = 3 - 4x$ is bijective (one-to-one and onto).

**Question 8:** Find the projection of the vector $\vec{a} = \hat{i} + 3\hat{j} + 7\hat{k}$ on the vector $\vec{b} = 7\hat{i} - \hat{j} + 8\hat{k}$.

**Question 9:** Formulate the following mathematically as a Linear Programming Problem (Do not solve):
A manufacturer produces two types of toys, A and B. Toy A requires 5 minutes for cutting and 10 minutes for assembling. Toy B requires 8 minutes for cutting and 8 minutes for assembling. There are 3 hours available for cutting and 4 hours available for assembling in a day. The profit is ₹50 on toy A and ₹60 on toy B. Formulate the LPP to maximize profit.

## SECTION C (12 Marks)
*Answer all questions. Each question carries 3 marks.*

**Question 10:** Find the value of $k$ so that the function $f(x)$ is continuous at $x = \frac{\pi}{2}$:
$$f(x) = \begin{cases} \frac{k \cos x}{\pi - 2x}, & \text{if } x \neq \frac{\pi}{2} \\ 3, & \text{if } x = \frac{\pi}{2} \end{cases}$$

**Question 11:** If $y = (\sin x)^x + \sin^{-1}(\sqrt{x})$, find $\frac{dy}{dx}$.

**Question 12:** Find the intervals in which the function $f$ given by $f(x) = 2x^3 - 3x^2 - 36x + 7$ is strictly increasing or strictly decreasing.

**Question 13:** A bag contains 4 red and 4 black balls. Another bag contains 2 red and 6 black balls. One of the two bags is selected at random and a ball is drawn from the bag which is found to be red. Find the probability that the ball is drawn from the first bag.
