# Biology Practice Test 01
**Format:** ISC Subjective  
**Portion:** Set 1 Midterm (Ch 2, 3, 4, 5, 6, 7, 8, 10, 13)  
**Time Allowed:** 45 Minutes  
**Maximum Marks:** 30  

**General Instructions:**
- All questions are compulsory. Internal choice is provided in Section D.
- Maintain neat handwriting and use a pencil for diagrams.
- Stick strictly to the word limits and use ISC-specific terminology.

---

## SECTION A (5 Marks)
*Answer all questions. Each question carries 1 mark.*

**Question 1:** Which of the following cells provide nutrition to the developing sperms?
(a) Leydig cells
(b) Sertoli cells
(c) Spermatogonia
(d) Primary spermatocytes

**Question 2:** Define *apomixis*. 

**Question 3:** Sickle-cell anemia is an example of:
(a) Point mutation
(b) Frameshift mutation
(c) Chromosomal aberration
(d) Aneuploidy

**Question 4:** Name the enzyme that catalyzes the process of reverse transcription.

**Question 5:** Which of the following factors does *not* disturb the Hardy-Weinberg equilibrium?
(a) Genetic drift
(b) Random mating
(c) Mutation
(d) Gene flow
