## SECTION C (21 Marks)
*Answer all questions. Each question carries 3 marks.*

**Question 18:** Differentiate $y = x^{\sin x} + (\sin x)^{\cos x}$ with respect to $x$. *(Hint: Use logarithmic differentiation carefully on each term).*

**Question 19:** Discuss the continuity of the function $f(x)$ at $x = 0$:
$$f(x) = \begin{cases} \frac{\sin 3x}{x}, & \text{if } x < 0 \\ 3, & \text{if } x = 0 \\ \frac{e^{3x} - 1}{x}, & \text{if } x > 0 \end{cases}$$

**Question 20:** Find the intervals in which the function $f(x) = \sin x + \cos x$, where $0 \le x \le 2\pi$, is strictly increasing or strictly decreasing.

*(Note: You must explicitly state all variable definitions and mandatory non-negativity constraints).*
